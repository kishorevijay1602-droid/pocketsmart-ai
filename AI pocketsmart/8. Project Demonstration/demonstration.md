# Project Demonstration

## Project Title

PocketSmart AI Budget Planner

## Demonstration Objective

The project demonstration will showcase the complete working flow of PocketSmart AI, including user authentication, AI-powered planning, recommendation generation, and recommendation history.

## Demonstration Flow

### 1. Home Page

Show the PocketSmart AI home page and explain the available planning modules.

### 2. User Registration

Demonstrate creating a new user account.

### 3. User Login

Log in using the registered account.

### 4. Dashboard

Show the dashboard and explain the available planner options.

### 5. Home Planner

Enter a sample budget and home requirements.

Generate the AI recommendation and show the result.

### 6. Party Planner

Enter a sample party budget and requirements.

Generate and display the AI-generated party plan.

### 7. Jewelry Planner

Enter a sample jewelry budget and requirements.

Upload an image if required and generate the AI recommendation.

### 8. Recommendation History

Open the History page and demonstrate that generated recommendations are stored and can be viewed.

### 9. Full Recommendation

Open a saved recommendation using the View Full Plan option.

### 10. Logout

Demonstrate logging out of the application.

## Deployment Demonstration

The deployed PocketSmart AI application will also be demonstrated using its public web URL.

## Demo Video

A screen-recorded demonstration video will be prepared and uploaded to Google Drive.

The Google Drive sharing permission will be configured as:

`Anyone with the link`

The publicly accessible Google Drive link will be submitted through the project submission form.

## Demonstration Outcome

The demonstration will show that PocketSmart AI provides a complete AI-powered budget planning workflow from user input to personalized recommendations and recommendation history.
