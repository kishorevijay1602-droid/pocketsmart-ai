# PocketSmart AI

## Topic Links

This repository contains the learning documentation completed for the PocketSmart AI project.

### 1. FastAPI Framework Knowledge
FastAPI is a Python framework used for building APIs and web applications.
It will be used for backend API development in the PocketSmart AI project.

### 2. Multi-AI Integration
The project requires integration with multiple AI providers using their APIs and API keys.

### 3. Python Async Programming
Python asyncio provides asynchronous programming using `async` and `await`.
It is useful for handling I/O-bound and network operations efficiently.

### 4. Jinja2 Template Engine
Jinja2 is a template engine used to generate dynamic content from templates.
It can be used with Python web applications.

### 5. HTTPX
HTTPX is a Python HTTP client that supports synchronous and asynchronous requests.
It can be used to communicate with external APIs.
